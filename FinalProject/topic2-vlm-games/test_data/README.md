# 固定课程测试集

| 游戏 | 问答数 | 状态文件 |

| Sokoban | 503 | 126个完整状态 |
| Maze | 504 | 84个完整状态 |

Sokoban、Maze 由参考生成器按自然输出重新生成，保留各题引用的状态 JSON。Snake 沿用原公开测试题和图片；其记录中的历史 `state` 路径仅为元数据，不对应本目录的实际文件。

三个测试集均公开，仅用于评测。禁止使用测试样本、答案或衍生数据训练；禁止使用 Snake 及相似游戏的数据训练。模型与配置选择依据独立的域内验证集。

`excluded-states.txt` 保存完整 Sokoban/Maze 测试状态指纹。参考生成器自动拒绝这些状态；自写或修改生成器同样须排除。检查不包含旋转/镜像等近似状态，不能用更换题目、渲染或文件名绕过完整状态排重。

`manifest.json` 记录文件 SHA-256，评测入口会校验。请勿修改测试题、图片、状态或排重清单。数据字段和检查范围见 [数据格式](../docs/data-format.md)。
