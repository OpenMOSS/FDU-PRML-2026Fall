# 选题二：大模型的多模态游戏推理能力训练和泛化研究

本项目以 Qwen2.5-VL-3B-Instruct 为基座，通过数据构建与模型训练，在域内游戏上取得显著提升，并探究如何让这种提升更好地泛化到域外游戏。

## 任务与提供材料

包含 Sokoban（推箱子）、Maze（迷宫）和 Snake（贪吃蛇）三个游戏。每个游戏包含难度递进的感知、理解与推理任务，均为根据游戏图像与问题作答的单轮问答，无需与游戏环境交互。其中，Sokoban、Maze 为域内游戏，Snake 为域外游戏。

课程提供两个域内游戏的参考数据合成代码、三个游戏各约 500 道测试题，以及统一的推理与评测代码。合成代码可生成图像、问题、答案及程序分析过程，并通过完整游戏状态比对，排除与域内测试集重合的样本。

课程不提供训练代码或训练教程，数据构建、训练框架和训练方法由各组自行决定。

## 实验要求

- 仅使用上述基座进行训练，须实际更新模型参数。
- 训练数据的构建方式不限，可使用所提供的参考代码，也可自行开发生成方法、引入其他游戏或使用其他模型辅助合成，须说明数据来源、所用模型及用量。
- 禁止构建或使用 Snake 及其相似游戏的数据进行训练。不得将测试样本、答案或其衍生数据用于训练；所有 Sokoban/Maze 训练数据均须排除与测试集完整游戏状态重合的样本，修改或自行实现生成器也须满足这一要求。
- 调参与 checkpoint 选择须依据自行划分的域内验证集。Snake 测试集仅用于分析域外泛化，不得用于选择模型或配置。
- 使用统一评测代码及提示词，不得修改其逻辑；评测采用温度 0、最大生成长度 4096 的解码设置。

## 提交与报告

提交 Hugging Face 格式的完整模型权重（LoRA 须先合并）、数据构建与训练代码、复现说明、评测输出及实验报告。提交渠道和截止时间以课程通知为准。

报告应清楚说明研究思路、数据与训练设置，通过实验论证方法的效果。除定量比较训练前后的域内、域外表现外，还须结合具体样例，对模型的行为与能力变化进行定性分析。

评价综合考虑任务表现、实验设计、分析与论证质量及可复现性，不以单一测试分数作为唯一依据。

## 材料使用

以下命令均在本目录执行。环境准备见[环境说明](docs/environment.md)，训练框架不受评测环境限制。

```bash
cd FinalProject/topic2-vlm-games

# 三个游戏完整评测：传入基座或合并后的完整模型目录
python evaluate.py --model /path/to/model --run-name baseline

# 生成域内数据，使用新的输出目录；参数表示棋盘数量
python generators/sokoban/main.py --boards 100 --output my-data/sokoban
bash generators/maze/generate.sh my-data/maze 60 30 10

# 检查生成数据是否与域内测试状态重合
python generators/state_guard.py my-data/sokoban/data.json
python generators/state_guard.py my-data/maze/data.json
```
